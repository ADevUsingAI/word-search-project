# 単語検索 | Word Finder

英単語・日本語の意味・品詞・ページ番号から検索する、スマートフォン向けの単語検索アプリです。

## できること

- 日本語の意味・英単語・品詞・ページ番号の4種類で検索
- 入力中に自動検索（検索ボタン不要）
- 同じ英単語がCSV内に複数行ある場合、意味・品詞・ページをまとめて表示
- 単語をタップすると、その単語に登録された意味などを表示
- 検索・単語表示の履歴を最大100件保存
- 前回の検索状態を復元
- 端末設定に合わせたダークモードと、ライト／ダークの手動切り替え
- HTTPSで公開した場合のオフライン表示
- iPhone／iPad／Android／PCに対応したレスポンシブ表示
- faviconはHTML内で定義。PWA用アイコンも同梱

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。画面・検索処理・履歴・設定を含む |
| `manifest.webmanifest` | PWAの名前・表示方法・アイコン設定 |
| `sw.js` | オフライン表示とキャッシュ |
| `icon-192.png` / `icon-512.png` | ホーム画面・PWA用アイコン |
| `README.md` | この説明書 |

**CSVファイルは同梱していません。** ご自身で用意した `1.csv`、`2.csv`、`3.csv` の3ファイルを、`index.html` と同じフォルダへ置いてください。CSVの中身をアプリに内蔵していないため、データを差し替えてもHTMLの編集は不要です。

## CSVの形式

`1.csv`、`2.csv`、`3.csv` の3ファイルを自動で読み込み、内容を統合して検索します。3ファイルは同じ列構成にしてください。ファイルが一部見つからない場合は、読み込めたファイルだけで動作します。


標準の列順は次のとおりです。

```csv
ID,英単語,発音記号,品詞,日本語の意味,ページ
```

2行目以降にデータを入れてください。アプリは `英単語` / `word` / `English`、`日本語の意味` / `meaning` / `訳`、`品詞` / `pos`、`ページ` / `page` などの一般的な列名も自動判定します。列名を省略する場合は、上記の標準順で読み込みます。

- 文字コードはUTF-8を推奨します。Shift_JISのCSVは、アプリの「CSVを読み込む」から文字コードを切り替えて読み込めます。
- 同じ英単語を複数行に分けて登録できます。アプリ側で同じ単語をまとめて表示します。
- 意味欄などに半角カンマ `,` を含める場合は、そのセル全体を半角ダブルクォーテーション `"` で囲みます。
- ページ欄は `123` または `"1, 2"` のように記載できます。
- 品詞は `名`、`動`、`形`、`副` などの略記でも読み込めます。

## GitHub Pagesで公開する

1. ZIPを展開します。
2. 展開したフォルダ内の `index.html`、`manifest.webmanifest`、`sw.js`、アイコン画像をGitHubリポジトリの最上位（root）へアップロードします。
3. 自分で用意したCSVを `1.csv`、`2.csv`、`3.csv` という名前で同じrootへアップロードします。
4. GitHubリポジトリの **Settings → Pages** を開き、公開元を **Deploy from a branch**、ブランチを `main`、フォルダを `/ (root)` にして保存します。
5. 表示されたGitHub PagesのURLをSafariで開きます。

3つのCSVを置かずに公開した場合、アプリ画面は表示されますが単語データは表示されません。3つのCSVはアプリ本体と同じ階層に配置してください。

## iPhoneで使う

1. SafariでGitHub PagesのURLを開きます。
2. 共有ボタンを押します。
3. **ホーム画面に追加**を選びます。
4. 追加したアイコンから起動できます。

## ローカルで使う

`index.html` を直接開いても画面は表示できますが、ブラウザのセキュリティ制限により `1.csv`・`2.csv`・`3.csv` を自動取得できない場合があります。その場合は、画面の **CSVを読み込む** から3ファイルをまとめて選択してください。PWA／Service Workerの機能はHTTPSで公開した場合に有効になります。

## 保存される情報

検索履歴、テーマ設定、前回の画面状態、読み込んだCSV（約1.8MB以内）は、その端末のブラウザ内に保存されます。別の端末や別ブラウザとは同期されません。ブラウザのサイトデータを消去すると、これらの情報も消えます。

## 補足

このZIPにはアプリのコードとPWA関連ファイルのみを含めています。教科書画像の単語一覧をCSV化したデータは含めていません。
